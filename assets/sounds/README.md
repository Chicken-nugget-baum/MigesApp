# Sounds

- `bell.mp3` – one toll of a church bell, cut (seconds 10–17.5) from "Church bell" #0135 by Joseph Sardin,
  https://bigsoundbank.com/detail-0135-church-bell.html – licence CC0 (public domain).
  Used for the Heiligkreuz-Kapelle (`js/audio.js`, `NB.Audio.bell`); the synthesized bell is the fallback when the
  file can't be loaded (e.g. from `file://`).
